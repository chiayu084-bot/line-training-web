核心重點

ecid 記錄最新值：同一用戶每次跳轉都會產生不同 ecid，Cookie 有效時間至少 24 小時。
訂單成立定義：Cookie 效期內所有導購訂單皆須回拋，含購物車跨店、多次購物等情境。
金額計算：甲 1,000 + 乙 1,500 = 2,500，優惠券 300，回拋總額 2,200。甲：880，乙：1,320。

首次訂單回拋 API（orderinfo）

訂單成立後須即時呼叫。POST https://buy-order-api.line.me/tracking/orderinfo
欄位型別說明
site 必填int固定值 2
shopid 必填intLINE 購物核發之商城代號
authkey 必填stringLINE 購物核發之認證代碼
ecid 必填string64碼英數混合用戶識別碼
timestamp 必填intUnix timestamp
hash 必填stringHMAC-SHA256 驗證碼
orderid 必填string訂單編號，支援 a-z A-Z 0-9 # - _
ordertime 必填stringGMT+8，格式 YYYY-MM-DD HH24:MI:SS
ordertotal 必填int訂單總金額，須等於 product_amount 加總
order_list[].product.product_name 必填string商品名稱
order_list[].product.product_type 必填stringnormal 或 3c
order_list[].product.product_id 必填string商品編號
order_list[].product.product_amount 必填int品項總金額，優惠券須按比例攤提。不可寫成 product_fee
order_list[].product.sub_category1 必填string第一層目錄名稱
order_list[].product.sub_category2 選填string第二層目錄名稱
orderinfo 金額欄位是 product_amount，orderfinish 才是 product_fee，切勿搞混。
欄位說明
payment_methodCASH / CREDITCARD / THIRDPARTY
third_paymentLINEPAY / APPLEPAY / GOOGLEPAY 等
card_brandVISA/MASTER/AMEX/JCB 等，不可回傳 0
bank_code發卡銀行代碼，三位數
card_number信用卡前六碼
delivery_methodHOMEDELIVERY / CVS / FASTDELIVERY / INSTORE / OTHER
cvs7ELEVEN / FAMILYMART / OKMART / HILIFE 等
temperatureNORMAL / CHILLED / FROZEN / OTHER
is_new_member1=首購，0=非首購
is_vip1=VIP，0=非VIP
is_app1=透過APP下單
custom_tag自定義行銷標籤
invoice_number兩位大寫英文 + 八位數字，例：AB11223344
random_number電子發票四位隨機碼
付款、物流、用戶身份及 custom_tag 只有 orderinfo 能提供，一旦成功就無法更新。

Hash 產生步驟

// Step 1: ordertime 做 MD5
ordertime_hashkey = md5('2018-02-01 22:05:15')

// Step 2: HMAC-SHA256
hash = hash_hmac('sha256',
  'orderid=20180201080001&ordertotal=500×tamp=1521011327',
  ordertime_hashkey)

// 結果：
073f5eceb14197c25563a7fd76125632dbe0809c679d2e7c384d028bde17d542

請款訂單回拋 API（orderfinish）

於訂單過鑑賞期後（平均 7–14 天）呼叫。POST https://buy-order-api.line.me/tracking/orderfinish
欄位型別說明
site / shopid / authkey / ecid / timestamp / hash / orderid-同 orderinfo
ordertime 必填string不可與 orderinfo 的值不同
feetotal 必填int請款總金額，等於 product_fee 加總
feetime 必填string消費者確認完成且過鑑賞期的時間，GMT+8
fee_list[].product.product_fee 必填int品項實際金額。不可寫成 product_amount
fee_list[].product.product_name/type/id/sub_category1-同 orderinfo，須一致
orderfinish 金額欄位是 product_fee，總金額是 feetotal。與 orderinfo 的欄位名稱不同！
// Step 1: feetime 做 MD5
feetime_hashkey = md5('2018-02-16 10:05:15')

// Step 2: 簽名字串含 feetime 與 feetotal
hash = hash_hmac('sha256',
  'orderid=20180201080001&feetime=2018-02-16 10:05:15&feetotal=500×tamp=1521011477',
  feetime_hashkey)

// 結果：
9ca2cf51ca2427d336b6f0e7f27e0527846060de295550528cfce58aff1108d7

部分退貨：fee_list 只放未退貨商品，金額扣除退貨品項。

整筆退貨時，完全不需要呼叫 orderfinish。

商品資料 Feed 規格

三支 API 總覽
檔案名稱更新頻率說明
product_full每日一次全部商品資料
product_partial每小時一次前一小時有異動的商品
cate_full每日一次全部商品目錄資料
IP 白名單：223.26.70.247、147.92.187.35、223.26.70.11
欄位必填說明
product_id必填唯一值，英數及 -，至多 50 字
product_name必填至多 100 字，不含促銷文字
description必填短描述，至多 5,000 字，不支援 HTML
l_description必填長描述，至多 60,000 字，支援 HTML
link必填https，中文須 urlencode
image_link必填https，更換圖片須更換 URL
color選填17 種定義值，多色用 / 區隔
欄位必填說明
availability必填in stock / preorder / discontinued
price必填原價，正整數，新台幣
sale_price選填特價，不可大於 price
product_type必填normal 或 3c
product_category_value必填對應 cate_full 目錄編號
age_group必填normal 或 adult（18+）
欄位說明
category_title目錄名稱
category_value目錄編號（唯一值）
category_value_parent上層目錄編號；第一層填 0
category_flag1=上架，0=下架
